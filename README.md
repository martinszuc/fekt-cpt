# 🔐 fekt-cpt — Cryptography Obsidian Vault

Personal Obsidian knowledge base for my cryptography studies (FEKT?).

## How to use
1. Clone the repo
2. Open the folder in **Obsidian**
3. Start at `Home.md` (or type `Ctrl/Cmd + O` → “Home”)

## Recommended plugins
- Dataview
- Excalidraw
- Spaced Repetition
- Templater

## Structure
- `Home.md` → main index
- `Days/` → daily lessons
- `Equations.md` → cheat sheet
